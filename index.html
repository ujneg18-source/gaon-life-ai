10  ·  KEY CASE

Parse와 Extract로
함께 확인한 질병코드
C18 → C18.7

엣지 케이스

직인이 질병분류기호를 가린 경우입니다. Information Extract는 진단서에서 질병코드 C18을, 입퇴원확인서에서는 C18.7을 추출했습니다.

같은 청구 건에서 서로 다른 질병코드가 나오자, 시스템이 이를 먼저 찾아 확인 항목으로 표시했습니다. 담당자는 Document Parse 원문에서 입퇴원확인서에 C18.7이 적혀 있는 것을 확인하고 최종 값을 확정했습니다.

어떻게 확인했나
  1. 진단서 Extract 값 C18과 입퇴원확인서 Extract 값 C18.7을 비교
  2. Document Parse 원문에서 입퇴원확인서의 C18.7 확인
  3. '질병분류기호 확인' 안내와 함께 원본 위치 표시
서로 보완한 지점

이 사례는 목업 데이터지만, 실제 청구 서류에서도 직인 · 도장이 글자를 가리거나, 사진이 흐리거나 접힌 자국이 남거나, 서류마다 질병코드를 C18과 C18.7처럼 다르게 적는 경우가 생깁니다. Parse의 원문과 Extract의 추출값, 그리고 다른 서류의 같은 항목을 함께 대조하면 한쪽에서 놓친 값을 다른 쪽이 잡아 줍니다. 두 제품은 서로를 검증하는 구조로 쓸 때 더 정확해집니다.
