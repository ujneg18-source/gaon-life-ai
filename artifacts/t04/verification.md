# T-04 브라우저 확인 — 2026-10-15

빌드된 Next.js를 127.0.0.1:3000, FastAPI를 127.0.0.1:8000에서 실행했다.
모든 계정과 화면의 데이터는 가상이다.

- 비로그인 루트 접근 → /login 리다이렉트 확인.
- 심사 담당자 한지원 로그인 → 메인 이름·역할 확인.
- 메인에서 워크스페이스 입구 이동 확인.
- 담당자 메뉴 5개, 운영 관리 직접 접근 거절 화면 확인.
- 검색 제출 → 준비 중 안내, 메뉴 안내 열기·닫기 확인.
- 로그아웃 → /login, 관리자 오세린으로 역할 전환 확인.
- 관리자 메뉴 6개, 운영 관리 접근·새로고침 뒤 로그인 유지 확인.
- 메인 어시스턴트 입구 및 우하단 링크는 준비 화면으로 연결한다.
