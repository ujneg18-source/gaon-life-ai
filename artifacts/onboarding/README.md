## 최종본: v2
- 메인4 / 업무 어시스턴트7 / 청구 검토함13 / 청구건 상세17 / 문서 분석·검토8 / 보완 처리7 / 검토 이력4 = 총60단계.
- 설명은 최대67자, 제목은 공통 Noto Sans KR/볼드, 마지막은 “궁금할 땐 언제든 ?를 눌러 주세요.”
- 최종 검사는 desktop-checks.json(1280×720), narrow-checks.json(729×800). 모든 단계의 대상 존재·화면 내 전체 표시·카드 위치·대상/설명 비중첩 통과. desktop-/narrow- 접두사 캡처가 최종본이다.
- 초기에 큰 영역을 중앙에서 강조하면 좁은 화면에서 카드와 겹쳤다. 설명 대상은 버튼/머리글/서류 목록 등으로 좁혔고, 설명 공간이 부족하면 먼저 위로 정렬했다. 화면 끝은 실제 내용이 아니라 강조 여백만 줄인다. 좁은 화면의 근거 패널은 설명할 때만 펼친다.
- v2/step-checks.json과 접두사 없는 캡처는 중간 검수다. 최종 검수 JSON을 우선한다.

## 데이터 격리
- 일반 업무 화면과 같은 컴포넌트를 렌더링하지만 API 응답과 원본은 가상 복사본이다. 실제 API 읽기/쓰기와 업로드를 차단한다.
- 안내 전용 전체 순회 전후15개 DB 테이블 내용이 동일한 것을 확인했다. 중간 비교에서는 동시 사용의 view/chat_read 로그2건이 추가되었으나 전용 재실행에서는 변경이 없었다.
- 이번 제작·검증의 LLM/Upstage 호출0회. 저장된 시연 답변을 재사용했고 평가/홀드아웃/약관 원문은 수정하지 않았다.
