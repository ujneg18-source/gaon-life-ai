# 청킹·검색 ablation

동일 새 구조 인덱스/머리말 임베딩/질문/정답. legacy는 이전 점수·BM25 정규화·가중치를 그대로 두고 주소 묶음만 새 구조로 바꾼 청킹-only 실험이다. dense는 추가 참고이며 재작성·BM25·재정렬이 없다. hybrid는 RRF·재작성·재정렬까지 적용한다. 운영 코드에는 legacy를 쓰지 않는다.

| 변경 | recall@3 |
|---|---:|
| 이전 인덱스 + 이전 검색 (정답 수정 후) | 70.83% |
| 구조 청킹 + legacy | 60.42% |
| 구조 청킹 + dense | 62.50% |
| 구조 청킹 + hybrid | 91.67% |
