# 01. 범위

## 주 사용자 (확정)
- 가온생명 보상팀 **고액 심사 담당자** (데모 계정 한지원) + **운영 관리자** (오세린)

## 대표 시나리오 (초안)
- 암 진단금 + 입원일당 + 실손 동시 청구 1건
- 경로: 실손24(영수증 · 세부내역서 · 처방전 데이터) + 앱 사진 업로드(진단서 · 조직검사 결과지 · 입퇴원확인서)

## 서류 Tier (확정 2026-10-15, 생명보험 기준)
| Tier | 처리 깊이 | 서류 |
|---|---|---|
| 1 깊게 | 추출 + 서류 간 교차검증 | 진단서, 조직검사 결과지, 입퇴원확인서, 수술확인서, 진료비 영수증 · 세부내역서 · 처방전(실손24 데이터) |
| 2 중간 | 핵심 항목 추출 | 통원확인서, 약제비 영수증, 영상 판독지, 후유장해 진단서, 사망진단서 · 시체검안서, 보험금 청구서 |
| 3 얕게 | 분류 + 존재 여부 (+ 개인정보 마스킹) | 신분증 사본, 통장 사본, 가족관계증명서, 기본증명서, 위임장, 인감증명서, 개인정보 동의서, 교통사고 사실확인원, 사고 경위서, 진료기록 사본 |
| 제외 | — | 화재증명원, 피해 · 수리 견적서 (손해보험 재물 · 배상 영역) |

## 범위 밖
- 보험금 지급 여부 결정 (사람이 함)
- 자동차보험 사고 심사
- 진료기록 사본 요약 (별도 과제)
- 실제 실손24 연동 (모의 JSON으로 대체)

## 데모 범위와 실제 도입 조건 (2026-10-15)
이 PoC는 **기능이 어떻게 동작하는지 보여주는 데모**다. 넓게 만들지 않고, 김유정 고객 청구 1건을 처음부터 끝까지 동작시킨다.

| 영역 | 데모에서는 | 실제 도입 시 필요한 것 |
|---|---|---|
| 약관 | 금감원 공개 표준약관 + 가상 특약 | 보험사 상품별 실제 약관 · 특약 (판 · 개정 이력 포함) |
| 사내 기준 | 직접 작성한 가상 매뉴얼 (필수 서류, 보완 문구) | 보상 업무 매뉴얼, 심사 기준, 내부 지침 |
| 법령 · 규정 | 참고 수준 | 보험업법, 개인정보보호법, 의료법 등 법률 검토 |
| 고객 · 계약 | 가상 고객 · 가상 증권 | 계약 · 가입 특약 · 청구 이력 (기간계 시스템 연동) |
| 서류 | 가상 서류 이미지, 실손24 모의 JSON | 실제 청구 서류, 실손24 연계 |
| 의약품 정보 | 소수 샘플 분류표 | 의약품 분류 데이터 (공공데이터 등) |
| 보안 · 권한 | 화면 표현만 | 담당자 권한, 조회 기록, 개인정보 마스킹, 사내 설치 환경 |
| 판단 | AI는 근거 제시까지 | 지급 여부는 담당자 결정 (변함없음) |
