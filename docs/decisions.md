## ADR-01 약관 청킹: 길이 기반 → 법률 계층 기반

### 맥락과 실물 실패

설명문은 정의·예시·분류·대조 같은 수사 구조로 문단의 의미가 완결되는 경우가 많다. 약관은 문서 › 보장종목 › 조 › 항 › 호 › 목의 귀속 구조가 의미를 결정한다. 단서("다만"), 조문 간 참조, 문서 간 중복 문장과 규범 위계도 보존해야 한다.

옛 kb.py(6694f85)의 실제 조각에서 실손 특약 제4조가 보장종목 구분 없이 묶여 질병 비급여에도 "(1) 상해 비급여" 맥락이 붙었다. ③항 1~16호가 약1,760자 조각에 들어갔고 줄 분할 뒤 조각에는 항의 머리 문장이 없었다. 주소는 제4조까지만 있어 호 인용이 불가능했다. 재현 근거는 artifacts/t18/runs/2026-10-16/t18c/legacy_chunk_evidence.md와 old_index.json에 보존한다.

### 결정

계층 파서로 노드·부모 주소와 보장종목을 유지한다. 열거형 항은 호 단위로 검색하고 부모 항 전체로 문맥을 확장하며 단서는 같은 조각에 둔다. 정의·참조를 한 단계 연결하고 문서/종목/조/항으로 묶는다. 검색에는 dense+BM25+주소의 RRF, 질문 재작성, top10 재정렬을 사용한다. 짧은 중복 호가 같은 항의 단서를 포함한 원문에 완전히 포함될 때만 더 완전한 원문을 우선한다.

## T-18 말투 처리 분리 (2026-10-16)

말투 지침을 근거 선택 단계에 섞은 첫 개발 평가(v1)는 일반 지급 절차 문장이 기존 안전 검사에 걸려 근거 답변을 잃었다. 최종 방식(v2)은 기존 사실/인용 선택 프롬프트를 유지하고, 인용과 의도·거절·버튼을 확정한 다음 본문만 별도 구조화 생성한다. 원문 인용은 문체 때문에 고치지 않는다. 문장화 후 위반은1회 재생성하고 남으면 유형만 기록한다. 숫자 소실이나 지급 확정 문구는 원래 사실 답변으로 되돌린다. 의미 동등성을 완벽히 증명하는 검사는 아니므로 개발 셋의 기존 품질 지표를 함께 평가한다. 새 말투 평가로 기존 홀드아웃을 재실행하거나 정답을 변경하지 않는다.
