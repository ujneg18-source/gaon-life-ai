신규 74항목에는 실손24 모의 데이터도 포함된다. 따라서 74/74는 전체 파이프라인 비교 결과이며 순수 OCR 모델 정확도로 해석하지 않는다. 예상값도 같은 정규화를 거친 뒤 필드별 비교했다.

김유정의 두 불일치는 진단코드 C18.7→C18, 병리 진단명에 한국어 번역이 추가된 값이다. C18은 원문 세분류 누락 및 CV-03 확인으로 남긴다. 알려진 실측 이슈 두 종류만 optional로 기록하며 다른 추가 이슈는 실패한다. `passed`는 이슈 기대값 검증 결과이고 필드 정확도 100%를 뜻하지 않는다.

개별 표·필드 차이는 `artifacts/t06/<sample_id>/png/{mock,live,cached}.json`에 저장했다. 실제 응답 원본은 git에서 제외한 `data/cache/`에만 보존한다.

## 실행과 재현

`backend/`에서 실행한다.

```bash
uv run python -m scripts.samples.gen_claim --customer all
uv run python scripts/samples/gen_claim.py --customer DEMO-C002
uv run python -m verify_samples --folder data/samples/lee_gaon
uv run python -m verify_samples --folder data/samples/han_nuri --cached
uv run python -m scripts.seed --demo
uv run python -m scripts.seed --demo --use-photo
```

- `customers.json`이 고객·계약·청구·서류 값의 단일 원본이다. 김유정 기존 생성기 진입점도 공통 생성기로 연결했다.
- PNG 22장을 추가했고, 수술확인서 회신용 1장은 별도다. 기존 김유정 7장 유지. 모든 신규 HTML은 1240×1754 A4로 CUA의 Playwright 브라우저에서 캡처했고 PNG로 저장했다. HTML/PNG 해시가 같으면 다시 캡처하지 않는다. 변경 파일 재렌더링용 CLI는 Playwright Chromium을 사용한다.
- `seed --demo`는 DB 행을 초기화한다. 이번 실행 전 DB는 무시 대상 `data/before-t06-demo.db`에 백업했다. 캐시가 없는 환경에서는 mock으로 정직하게 표시하고 실제 API를 자동 호출하지 않는다.
- DB `Document.provenance`와 화면의 개발 검증 문구로 실제/모의를 구분한다. `SHOW_DEVELOPMENT_BADGES=false`로 화면 개발 표시만 숨긴다.
- 전체 백엔드 62 passed / live 1 deselected, Ruff·포맷 통과. 프론트 lint/typecheck/format/build 통과.
- CUA로 13건 인박스·개발 출처·한누리 약관 대조·처방전/영수증 원본 1240×1754 로딩·기본 비교 100% 확인. 캡처: `artifacts/t06/inbox.jpg`, `inbox-viewport.jpg`, `han-nuri-detail.jpg`, `han-nuri-review.jpg`.

## 호출량과 비용 추정

이번 신규 실제 검증은 이가온 2장·한누리 1장, 물리 문서 3페이지다. Classify/Parse/Extract 각각 3회로 총 9회 호출했다. 김유정과 재검증은 캐시만 사용했다. 기존 예산 원장의 입력 페이지 예약은 12에서 21/30으로 증가했다(단계별 페이지 합산). 원장을 삭제하거나 초기화하지 않았다.

[공식 API 요금표](https://www.upstage.ai/pricing/api) 기준, 페이지당 Classify $0.004, Parse $0.01~0.03, Extract $0.04~0.06을 적용하면 **3 × ($0.004 + $0.01~0.03 + $0.04~0.06) = $0.162~0.282**, VAT 10% 별도다. 실제 과금 등급·콘솔 차감액은 미확인이다. Studio 요금과 혼동하지 않는다.

## 남은 사항

- 사진은 사용자가 제작한다. 폴더/이름/중복 방지/fallback은 구현했고 김유정 01·02·03 + 한누리 07만 제작하도록 프롬프트를 갱신했다. 사진 OCR 비교와 추가 호출 비용은 아직 측정하지 않았다.
- 90일 면책·소액암 안내는 지급 확정/금액 산정이 아니다. 실손24 수신과 보완 발송도 모의다.
