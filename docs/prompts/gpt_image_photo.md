# GPT 이미지 프롬프트 — 서류를 "폰으로 찍은 사진"처럼

입력: `data/samples/kim_yujeong/png/*.png` 중 한 장을 첨부. **한 번에 한 장씩.**

## 기본 프롬프트 (그대로 붙여넣기)
```
첨부한 서류 이미지를, 이 종이를 출력해서 책상 위에 놓고 스마트폰으로 찍은 사진처럼 바꿔 줘.

반드시 지킬 것:
- 서류 안의 모든 글자, 숫자, 날짜, 금액, 표, 선, 도장, "SAMPLE · 가상 데이터" 표시는 한 글자도 바꾸거나 지우거나 새로 쓰지 마.
- 서류의 배치(표 위치, 칸 크기)도 그대로 유지해.
- 새로운 로고, 인증 마크, 바코드, QR코드, 주소, 전화번호를 추가하지 마.

바꿀 것 (사진 느낌만):
- 종이 질감과 가벼운 구김
- 실내 조명, 약한 그림자
- 아주 약간 기울어진 촬영 각도 (5도 이내)
- 배경은 밝은 회색 책상

글자는 사람이 읽을 수 있을 만큼 선명하게 유지해 줘.
```

## 변형 (서류별로 하나씩만 섞어 쓰기)
| 용도 | 바꿀 줄 |
|---|---|
| 확인 필요 사례 만들기 (01_diagnosis) | "아주 약간 기울어진 촬영 각도" → "약간 흔들려서 살짝 흐린 사진, 그래도 글자는 읽을 수 있게" |
| 그림자 사례 | "약한 그림자" → "사진 왼쪽 위에 손 그림자가 살짝 드리워진" |
| 구김 강하게 | "가벼운 구김" → "한 번 접었다 편 자국과 구김" |
