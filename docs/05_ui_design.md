## SCR-01 로그인
- 가운데 로고 + "가온생명 AI" + 한 줄 설명
- 버튼 2개: **심사 담당자로 시작** (한지원) / **관리자로 시작** (오세린)
- 하단 작은 글씨: "데모 계정입니다. 모든 데이터는 가상입니다."
- 로그인 후 SCR-02로 이동, 상단 오른쪽에 이름 · 역할 · 로그아웃

## SCR-02 메인
- 상단: 로고, 로그인 사용자
- 가운데 질문 "오늘은 어떤 업무를 도와드릴까요?" + 입구 2개
  - 업무 어시스턴트 (AI 챗봇) → SCR-20
  - 보험금 지급 서류 검토 (워크스페이스) → SCR-10

## 워크스페이스 공통
- 왼쪽 메뉴 6개: 청구 검토함 · 청구건 상세 · 문서 분석 · 검토 · 보완 처리 · 검토 이력 · 운영 관리(관리자만)
- 위: 검색창 "고객 이름 · 청구번호 · 증권번호로 검색"
- 오른쪽 아래: "가온 AI에게 묻기"(추천 질문 → 챗봇), "?" 메뉴 안내

## SCR-10 청구 검토함
- 상태 필터 칩: 전체 · 검토 필요 · 보완 요청 · 자동 통과 (건수 표시)
- 표: 청구번호 · 고객 · 청구 유형 · 접수 · 상태 · AI 검토 결과
- 행 클릭 → SCR-11

## SCR-11 청구건 상세
- 머리: 고객 · 청구번호 · 접수일 · 첨부 서류 수 · 상태
- 단계 4개 (클릭 이동 + 이전/다음)
  1. **서류 확인**: 제출 서류 체크리스트(누락 빨강, "보기" → SCR-12) + 추출된 청구 정보(직접 수정)
  2. **정보 대조**: 대조 항목 · 서류 A · 서류 B · 결과 표
  3. **검토 결과**: 남은 확인 건수 · 누락 서류 · 약관 대조 결과 + 담당자 메모
  4. **완료**: 보완 요청 보내기 / 지급 심사로 보내기 (열린 이슈가 있으면 잠김)

## SCR-12 문서 분석 · 검토
- 서류 탭 (진단서 · 조직검사 결과지 · 입퇴원확인서 · 진료비 영수증 · 세부내역서 · 약제비 영수증)
- 왼쪽: 원본 뷰어
  - 확대/축소 − / + (60~160%)
  - 추출 위치 박스: 일치 보라 실선 · 불일치 주황 실선 · 저신뢰 주황 점선
  - 원본 비교 모드: 두 서류 나란히 + "비교 닫기"
- 오른쪽 (왼쪽과 같은 높이)
  - **누락 · 불일치 · 확인 필요**: 한 줄형 (상태 · 제목 · [원본 비교/원본 보기] [확인]) + 설명 한 줄
  - **정규화 결과 · 표준 스키마** (실손24 규격 기준): 항목 · 값(질병코드는 KCD 명칭) · 출처(Parse/OCR/데이터) · 신뢰도(기준 미만 강조)

## SCR-13 보완 처리
- 왼쪽: 보완 요청 목록 (작성 중 · 회신 대기 · 제출 완료)
- 오른쪽: 요청 서류, 채널(알림톡/문자), 알림톡 미리보기(문구 수정 가능), [AI로 문구 다듬기] [보내기]
- 보내기 = 모의 발송. 상태만 "회신 대기"로 바뀐다

## SCR-14 검토 이력
- 시간 · 행위자(고객 · 가온 AI · 담당자) · 행동 · 설명 타임라인

## SCR-15 운영 관리 (관리자)
- 자동 통과 기준: 신뢰도 슬라이더 (0.70~0.99)
- 청구 유형별 필수 서류 표 (편집)

## SCR-20 업무 어시스턴트
- 왼쪽: 새 채팅 · 히스토리 (요약 제목 + 시간)
- 가운데: 대화 + 왼쪽 가장자리 질문 바로가기 막대(hover 미리보기, 클릭 이동) + 입력창
- 오른쪽: 답변 근거 패널 (번호 클릭 시 강조, 가상 문서 표시)
- 답변 형식: 요약 한 줄 → 문제만 목록 → 근거 번호 → 다음 행동 버튼
