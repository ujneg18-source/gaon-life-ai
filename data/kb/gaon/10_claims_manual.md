# 보상 업무 매뉴얼

> **가상 사내 문서입니다.** 시연용으로 작성했습니다. 실제 회사 기준이 아니며, 공개 표준약관을 인용한 부분은 조항 번호를 함께 적었습니다.

## 1. 처리 흐름
1. **접수:** 앱 업로드 서류와 실손24 전송 데이터를 청구 건에 연결합니다.
2. **문서 분석 (AI):** 서류 종류를 나누고, 서류별 항목을 표준 스키마로 읽어 정리합니다.
3. **자동 검토 (AI):** 필수 서류 누락, 서류 간 불일치, 확인이 필요한 값을 찾습니다.
4. **담당자 검토:** AI가 올린 항목만 확인합니다. AI는 근거를 보여 줄 뿐, 지급 여부를 판단하지 않습니다.
5. **보완 요청 또는 지급 심사 이관:** 누락이 있으면 보완을 요청하고, 확인할 항목이 모두 끝나면 지급 심사로 보냅니다.

## 2. 청구 유형별 필수 서류

| 청구 유형 | 필수 서류 | 함께 확인할 점 | 근거 |
|---|---|---|---|
| 암 진단금 | 진단서, 조직검사 결과지 | 진단서에 질병분류기호(세분류까지). 소액암 여부 확인 | 암진단특약 제3조 · 제6조 |
| 입원일당 | 입퇴원확인서 | 입원일 · 퇴원일 · 병명 | 질병입원일당특약 제4조 |
| 수술비 | 수술확인서 | 수술명 · 수술일 · 수술 코드 | 질병수술비특약 제4조 |
| 통원일당 | 통원확인서 | 통원일 · 병명 | 질병통원일당특약 제2조 |
| 실손 (입원 · 통원) | 진료비 계산서 · 영수증, 진료비 세부산정내역 | 항목 구분이 되는 **법정 서식 영수증**이어야 함. 진료비 납입확인서는 받지 않음 | 기본형 실손의료보험 표준약관 제7조 |
| 실손 (약제비) | 약제비 계산서 · 영수증, 질병분류기호가 적힌 처방전 | 처방전에 없는 약은 처방조제비가 아님 | 기본형 실손의료보험 표준약관 제7조 |
| 후유장해 | 후유장해 진단서 | 장해 부위 · 지급률 | 생명보험 표준약관 제7조 |
| 사망 | 사망진단서(시체검안서), 가족관계증명서, 기본증명서 | 보험수익자 확인 | 생명보험 표준약관 제7조 · 제11조 |
| 공통 | 청구서, 신분증 | **앱 청구는 앱 입력 · 본인인증으로 면제** | 생명보험 표준약관 제7조 |

- 대리 청구: 위임장과 청구권자 인감증명서(또는 본인서명사실확인서)를 추가로 받습니다.
- 재해(사고) 청구: 사고 사실을 증명하는 서류(교통사고 사실확인원 등)를 추가로 받습니다.

## 3. 서류 확인 기준
1. **발급 기관:** 의료법상 국내 의료기관(또는 국외 의료기관)에서 발급한 서류여야 합니다. (생명보험 표준약관 제7조 ②)
2. **환자 정보:** 모든 서류의 환자 이름이 같아야 합니다.
3. **발행일:** 진단서 · 확인서의 발행일은 진료일 이후여야 합니다.
4. **직인 · 서명:** 직인이나 의사 서명이 없거나 알아볼 수 없으면 확인 필요로 둡니다.
5. **질병분류기호:** 세분류(소수점 아래)까지 확인합니다. 세분류가 빠지거나 잘못 읽히면 소액암 · 일반암 구분이 달라질 수 있습니다.

## 4. 서류 간 교차검증 기준

| 규칙 | 내용 | 담당자 확인 방법 |
|---|---|---|
| CV-01 진단일과 병리 보고일 | 진단서의 진단일이 조직검사 결과지의 보고일보다 빠르면 확인 필요 | 암 진단확정일은 병리 보고일 기준이므로(암진단특약 제3조 ③), 진료 기록으로 진단 경위를 확인합니다 |
| CV-02 입원 기간 | 입퇴원확인서와 세부내역서의 입원 일수 비교 | **1일 차이는 산정 방식 차이일 수 있습니다**(질병입원일당특약 제5조). 입원일 · 퇴원일이 같은지 먼저 보고, 2일 이상 차이나 날짜 자체가 다르면 의료기관에 확인합니다 |
| CV-03 질병코드와 병리 진단 | 진단서 질병분류기호와 조직검사 결과지 병리 진단이 서로 맞는지 | 진단서 원본과 결과지를 나란히 놓고 확인합니다 |
| CV-04 수술 기록과 수술확인서 | 세부내역서에 수술 행위가 있는데 수술확인서가 없으면 누락 | 수술비특약 가입 여부를 보고 보완을 요청합니다 (질병수술비특약 제5조) |
| CV-05 환자 이름 | 서류마다 환자 이름이 같은지 | 다르면 서류 재제출을 요청합니다 |
| CV-06 보장 기간 | 진료 · 진단 날짜가 계약의 보장 기간 안인지 | 기간 밖이면 해당 특약 보험금 대상이 아닙니다. 계약 정보를 다시 확인합니다 |

## 5. AI가 "확인 필요"로 올리는 경우
| 이유 | 뜻 | 담당자 할 일 |
|---|---|---|
| 신뢰도 낮음 | 문서 AI가 스스로 값을 확신하지 못함 | 원본에서 값을 직접 읽고 확정합니다 |
| 원문과 다름 | 추출한 값이 원문 글자와 다름 (예: 원문 C18.7, 추출 C18 → 세분류 누락) | 원본 위치를 열어 올바른 값으로 고칩니다 |
| 형식 오류 | 날짜 · 질병코드 · 금액 형식이 맞지 않음 | 원본 확인 후 수정합니다 |
| 서류 간 불일치 | 4장 교차검증 규칙에 걸림 | 4장 확인 방법을 따릅니다 |

- 신뢰도가 높아도 원문과 다르면 확인 필요로 둡니다. AI의 확신은 정확도를 보장하지 않습니다.

## 6. 실손 비급여 항목 확인
다음 비급여 비용은 실손의료보험에서 보상하지 않습니다. 해당 항목이 보이면 **"보상 제외 가능성"**으로 표시하고 담당자가 확인합니다. 단정하지 않습니다.

| 항목 | 기준 | 근거 |
|---|---|---|
| 영양제 · 비타민제 등 | 원칙적으로 보상하지 않음. 다만 보상하는 질병 치료에 허가 사항대로 쓰인 경우 등은 치료 목적으로 보아 보상 | 실손의료보험 특별약관1 · 2 제4조 ③ 제2호 |
| 호르몬 투여 · 보신용 투약 · 의약외품 | 보상하지 않음 | 특별약관2 제4조 ③ 제3호 |
| 진료와 무관한 비용 | TV시청료 · 전화료 · 각종 증명료, 임상적 소견과 무관한 검사비, 간병비 | 특별약관2 제4조 ③ 제5호 |

- **처방전에 없는 일반의약품**은 처방조제비가 아닙니다. 영수증 항목을 처방전과 대조합니다.
- 영양제가 처방전에 있고 치료 목적이 진료 기록으로 확인되면 보상 대상일 수 있습니다. 이 판단은 담당자가 합니다.

## 7. 보완 요청
- 누락 서류가 있으면 보완 요청을 보냅니다. 문구는 `11_supplement_templates.md`를 따릅니다.
- 요청에는 서류 이름, 발급처, 제출 방법을 꼭 넣습니다.
- 보완 요청 후 회신이 오면 새 서류로 다시 자동 검토를 돌립니다.

## 8. 지급 심사로 보내는 기준
- 확인 필요 항목이 모두 확인 완료일 것
- 누락 서류가 없을 것 (보완 회신 완료)
- 지급 여부와 금액은 지급 심사 담당자가 결정합니다.

## 9. 개인정보
- 신분증 · 통장 사본의 번호는 화면과 기록에서 가립니다.
- 담당자는 배정된 청구만 봅니다. 모든 조회는 검토 이력에 남습니다.
- 계약 · 보험금 지급 목적 외에는 개인정보를 쓰지 않습니다. (생명보험 표준약관 제41조)

## 10. 업무 어시스턴트(AI 챗봇) 사용 원칙
- 답변은 약관 · 매뉴얼 근거와 함께 받습니다. 근거가 없으면 "관련 규정을 찾지 못했어요"라고 답합니다.
- AI는 지급 여부를 말하지 않습니다. "보상 제외 가능성", "확인 필요"처럼 판단 근거까지만 제시합니다.
