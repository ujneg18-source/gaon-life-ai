# 김유정 시연 서류 세트 (가상)

| 파일 | 서류 | 경로 | 심어 둔 문제 |
|---|---|---|---|
| 01_diagnosis | 진단서 | 앱 사진 | 진단일 09.18 < 병리 보고일 09.21 (CV-01), 질병분류기호 위 직인 |
| 02_pathology | 병리조직검사 결과지 | 앱 사진 | 보고일 09.21 |
| 03_admission | 입퇴원확인서 | 앱 사진 | 입원 9일 (CV-02) |
| 04_medical_receipt | 진료비 계산서 · 영수증 (입원) | 실손24 | 8일, 환자부담 841,600원 |
| 05_medical_detail | 진료비 세부산정내역 | 실손24 | 8일 (CV-02), 수술 항목 있음 → 수술확인서 누락 (CV-04) |
| 06_prescription | 처방전 | 실손24 | 카페시타빈정 · 온단세트론정 |
| 07_pharmacy_receipt | 약제비 영수증 | 앱 사진 | 종합비타민정(일반의약품) — 처방전에 없음, 약관 대조 대상 |
| (없음) | 수술확인서 | — | 일부러 만들지 않음 |

- `html/` 서식 원본 · `png/` 깨끗한 캡처(1240×1754, A4 150dpi) · `answers/` 정답 JSON (`_claim.json`은 청구 단위 정답)
- 값은 `backend/scripts/samples/gen_kim_yujeong.py`의 한 곳에서 정의. 고치면 다시 실행 → HTML · 정답이 같이 바뀐다
- 금액: 급여 본인부담 5%(암 산정특례), 합계는 코드로 계산해 서식과 정답이 항상 일치
- 모든 기관 · 인물 · 주소 · 코드는 가상이며 각 장에 "SAMPLE · 가상 데이터" 표시

## 사진처럼 만들기 (GPT 이미지)
`docs/prompts/gpt_image_photo.md`의 프롬프트로 `png/`를 하나씩 변환 → `photo/`에 저장 → Parse로 정답과 대조해 글자가 바뀐 이미지는 버린다.
